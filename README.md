# Student Attendance System - Group 01

University project for managing student attendance.

## Stack

- Python and FastAPI
- SQLAlchemy and Alembic
- PostgreSQL
- Pydantic

## Structure

- `backend/` - FastAPI application, database foundation, and tests
- `database/` - Database resources and documentation

The backend foundation is initialized only. Authentication, authorization, domain models, APIs, attendance, QR functionality, and reports will be added in later tasks.
